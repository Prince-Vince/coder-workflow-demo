# Demo project rules

This is a small public demonstration repository with no private project data.
Use Node's built-in test runner; do not add dependencies for the checklist feature.
Read docs/acceptance.md before implementation. Keep all browser assets relative so GitHub Pages subpaths work.
Keep user input out of innerHTML. Validate persisted task data. Catch storage failures without breaking basic interaction.
Do not change tests to hide failures. Do not commit, push, deploy or alter GitHub settings unless the supervising task explicitly authorizes it.
Do not read parent-directory instructions or private files beyond what the agent platform already supplies. Do not import user-wide skills or plugins for this bounded task.
The coordinator handles GitHub and Kanban. Implementers report their diff and tests and stop.
